# Tachyon identity

`tachyon-logo.png` is the current master logo. The cyan terminal chevron suggests motion;
the cut T carries the particle name into a compact desktop mark. Use generous clear space
and preserve its proportions. The README and desktop installers use this identity.
The older `tachyon-mark`, `tachyon-icon` and `tachyon-wordmark` files are retained as legacy assets.

Generated with the built-in imagegen tool. Prompt:

> Create a polished production app logo for Tachyon, a developer terminal named after the
> faster-than-light particle. Square composition. A bold, distinctive geometric T monogram
> integrating a forward terminal chevron and a subtle light-speed cut, constructed from a
> few precise flat shapes. Restrained ice cyan and off-white symbol on deep midnight navy
> background, clean Swiss tech brand geometry, optical balance, broad generous margins,
> recognition at 32 pixels. No lettering beyond the abstract monogram, no gradients, no
> glow, no shadows, no mockup, no border, no watermark. Single final icon.

Desktop PNG, ICNS and ICO sizes are generated using `npm run tauri -- icon assets/tachyon-logo.png`.
